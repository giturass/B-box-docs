# 默认值与限制

以下数值依据[固定源码版本](./sources.md)。KiB / MiB 分别是 1024 / 1048576 字节。记录、改写、拦截脚本、主动 HTTP 和资源各有独立限额。

## 开关与范围

| 项目 | 默认 | 范围或行为 |
| --- | --- | --- |
| MITM / HTTP 改写 / 脚本 `enabled` | false | 三个独立开关 |
| MITM `hosts` | 空 | 最多 256 项；空列表不解密 |
| MITM `ports` / `packages` | 空 | 空时不附加对应限制 |
| MITM `tcp` / `h2` | false | 非 HTTP TLS / HTTP/2 可选开启 |
| MITM `skip_server_cert_verify` | false | 默认验证真实上游 |
| MITM `block_quic` | true | 只作用于可观察名称且命中范围的 QUIC |
| 改写 / HTTP 脚本 / 记录端口 | 80、443、8080、8443 | 各自配置，最多 32 项；按原始目标端口 |
| 应用筛选 | 空列表 | 不限应用；指定后未知归属不能匹配 |

## 配置与正文

| 项目 | 默认 | 上限 |
| --- | --- | --- |
| MITM 配置大小 | — | 64 KiB |
| 单个改写/脚本扩展 JSON | — | 2 MiB |
| 声明式规则总数 | — | 256 |
| HTTP + Cron 脚本总数 | — | 256 |
| 每个扩展的资源数 | — | 256 |
| 改写请求正文及输出 | 32 MiB | 32 MiB |
| 改写响应正文及输出 | 1 MiB | 10 MiB |
| 拦截脚本 `max_body_bytes` | 1 MiB | 32 MiB；`-1` 表示 32 MiB 硬上限 |
| 主动 HTTP 客户端正文 | 32 MiB | 32 MiB；可单独调小 |
| Map Local 文件 | — | 15 MiB |
| JavaScript 源码 | — | 128 KiB |

改写兼容字段 `max_body_bytes` 可作为未指定方向的共同值（最多 10 MiB），方向字段优先。脚本单条 HTTP 规则可覆盖脚本扩展的 `max_body_bytes`。不要把脚本的 `-1` 当作无限制。

正文处理、解码、脚本与资源共享 384 MiB 工作预留预算。预算不足时会跳过未开始的正文工作及相应脚本、保留原流并记原因；这不是进程内存硬限制，也不代表手机可稳定承担这么多内存使用。

## 执行与联网

| 项目 | 默认或上限 |
| --- | --- |
| HTTP / Cron 单次总时限 | 默认 5000 ms，可设 1～86400000 ms |
| HTTP 解释器 | 最多 4 个 |
| Cron worker / 解释器 | 独立最多 2 个 |
| 主动 HTTP 单次请求超时 | 默认 5 秒，最大 86400 秒，受脚本总时限约束 |
| 主动 HTTP 并发 | 单次脚本最多 20 个 |
| 主动 HTTP 累计次数 | 默认不限；`max_requests` 可设正整数 |
| `allowed_origins` | 最多 16 项；省略/null 不限制，空数组禁止 |
| 主动 HTTP / URL 资源重定向 | 最多 10 次 |
| 待执行定时器 | 单次 VM 最多 64 个 |
| 定时器 delay | 0～86400000 ms，实际最小 1 ms |
| 日志 | 每次脚本最多 10 条，每条 2 KiB |

HTTP 等待解释器会消耗时限；Cron 排队不消耗，出队后开始计时。停止服务或 `$done` 会取消该次执行的在途工作。

## 正则、jq 与编码

| 项目 | 上限或行为 |
| --- | --- |
| 正则表达式 / jq 表达式 | 4096 字节 |
| 正则捕获组 | 32 个 |
| 单次正则替换 | 8192 处 |
| 回溯匹配 | 单次 200 ms，同方向累计工作预算 500 ms |
| jq | 同方向累计 500 ms，最多 8192 个输出值、256 层输出嵌套 |
| Content-Encoding | 最多三层，逐层检查解码上限 |
| 编码支持 | identity、gzip/x-gzip、deflate、br、zstd |

RE2 线性匹配不消耗回溯期限，仍受输入及替换次数限制。响应超限与编码问题可能跳过正文改写，具体见[Body Rewrite](../rewrite/body.md)。

## 记录、缓存与存储

| 项目 | 限制 |
| --- | --- |
| 请求记录 | 300 条，磁盘 32 MiB |
| 每方向保存正文 | 默认 64 KiB，最大 1 MiB |
| 头部 / trailers | 分别最多 64 KiB |
| 预览与 HAR 解码 | 最多 64 KiB |
| URL 资源缓存 | 合计 64 MiB |
| 存储单值 | 4 MiB |
| 单命名空间 | 128 键，序列化 JSON 32 MiB |
| 所有命名空间 | 256 个，合计 64 MiB |
| 单次脚本读写 | 64 次 |

这些容量不互相替代。提高抓取正文限额不会提高脚本、jq 或主动请求的处理上限。
