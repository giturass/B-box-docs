# 记录、详情与导出

**工具 → 连接与请求** 同时展示当前连接和已保存的抓取记录。MITM、改写与脚本由配置负责；可以只记录不改写，也可以在不记录时继续改写。

## 开始记录

1. 启动 B-box 本地服务，确认运行成功。
2. 在页面菜单的抓包设置中选择应用、原始目的端口、正文保留方式及域名提取。
3. 开始记录，再让目标客户端发出新请求。
4. 选择“抓取记录”筛选，按域名、URL 等搜索并打开详情。

抓取期间不能修改记录设置，需要先停止。尚未被接管的旧连接需要由目标应用重新建立；开启记录不能补录此前正在传输的正文。

## 连接和请求怎样展示

页面默认显示全部网络活动，可切换“活动”“抓取记录”“已结束”。普通 TCP/UDP、未解密 HTTPS 以连接行展示；已保存的 HTTP 请求、TLS/TCP 和仅域名记录分别成行。

同一 HTTP/1.1 连接的多个请求或 HTTP/2 流保留各自的请求 ID，通过精确的 `connectionId` 关联。在当前筛选中已有请求代表某条连接时，列表省略重复连接行。已完成请求不会把仍存活的 keep-alive 连接标为关闭。

搜索覆盖 URL、方法、状态、协议、应用、路由与来源/目标等已观测字段。每次展开 50 条只影响展示，尚未展开的匹配历史仍可搜索和导出。请求行显示自身正文计数，连接行显示核心连接流量，两者不能相加作为总量。

## 区分记录类型

| 类型 | 能看到什么 | 说明 |
| --- | --- | --- |
| HTTP / HTTPS | URL、方法、状态、头部、正文、时长等 | HTTPS 需要成功完成 MITM |
| 仅域名 | 可见的 TLS/QUIC 名称 | 只观察到名称，不表示已解密 |
| TLS/TCP | 已保存的双向解密字节与 TLS 元数据 | 非 HTTP 流，不执行 HTTP 改写 |

HTTPS 和 TLS/TCP 可记录真实 SNI、两端 TLS 版本、客户端/上游 ALPN 及上游叶证书摘要。Mock 没有实际连接上游时，不会编造上游 TLS 信息。

## 正文分页与完整性

正文卡片显示保存字节数、总字节数，以及截断、未完成、Base64 等状态。每次读取一个 **16 KiB 正文页**，用上一页/下一页继续查看；存在下一页只表示尚未读完，不等于正文被截断。

默认查看支持编码的解码后内容。二进制页用 Base64 展示；编码不可用时回退到原始保存字节并显示原因。分页偏移按当前原始或解码表示计算，UTF-8 字符不会在页边界拆开。

单页内的完整 JSON 可切换原文与格式化；格式化输出过大时保留原文。**“复制本页正文”只复制当前页原文**，不复制其他页面，也不受格式化切换影响。需要完整已保存内容时使用导出。

## 请求 ID 与连接 ID

请求自身 ID 用于详情、正文与导出。详情中的“查看连接”可以打开原始连接及其关联请求；跨目标改写时，记录的出站和路由仍描述原连接。

连接关闭或从近期连接列表消失后，请求记录仍保留。缺少关联的旧记录也可以查看。菜单中的“关闭底层连接”会影响该连接上的所有请求，与停止记录、清空记录是不同操作。

## 默认记录边界

| 项目 | 默认或行为 |
| --- | --- |
| 目标端口 | 80、443、8080、8443；按原始目的端口，不设条数配额 |
| 应用范围 | 空列表不限应用 |
| 保存条数、磁盘总量、头部及 trailers | 不设固定配额，记录保留到清空 |
| 每方向正文 | 默认 64 KiB；可填写正整数字节数或选择“保存完整正文”（`-1`） |
| 正文阅读 | 每页 16 KiB，按需读取后续页 |
| HAR / cURL | 流式读取保存内容，不受详情页大小限制 |

达到用户设置的保存上限只影响记录，不截断实际转发流量。记录正文限额与改写、脚本的正文限额分别设置。

## 导出

| 导出类型 | 使用条件 |
| --- | --- |
| HAR | 导出当前筛选下的全部匹配 HTTP 记录，包括尚未展开的条目；保留完整性标志 |
| cURL | 完整、未截断、没有 trailers 的 HTTP 请求 |
| 域名 | 对当前搜索条件下保留记录中的域名去重 |

普通连接、TLS/TCP 和仅域名记录不进入 HAR，也不能导出 cURL。HAR 的 trailers 放在 `_trailers`，压缩原文可保留在 `_rawBody`，耗时只有总时长。导出使用已保存内容，无法恢复超过记录限额或停止录制后未保存的部分。

## 停止与清空

停止记录会封存当前内容，迟到数据不再更新这些记录；处理和转发继续运行。下次开启记录从新 HTTP 请求或新 TCP 流边界开始。

停止服务后仍可读取已保存记录。清空抓取记录不关闭连接，也不会删除脚本持久数据、远程资源缓存或 CA。切换远程会话后只显示远端连接，停止本地记录，并禁止读取本地记录与证书。

## 在哪里看错误

运行错误和脚本 `console` 输出进入现有 **服务日志**，遵守核心日志等级。没有独立的“抓包日志”页面。需要查看 `console.log` 时，确保配置日志等级允许 `info`，页面筛选也没有隐藏它。
